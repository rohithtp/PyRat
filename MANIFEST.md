## 🏴‍☠️ PyRat: The High-Seas System Monitor

**PyRat** is a lightweight, terminal-based powerhouse designed for developers who want to keep a "weather eye" on their system resources without leaving the command line. Built with the speed of the **Ratatui** engine and the flexibility of **Python**, PyRat transforms raw system telemetry into a sleek, keyboard-driven dashboard.

Whether you're debugging a memory leak or just enjoy the aesthetic of a high-performance TUI (Terminal User Interface), PyRat provides a real-time "Crew Manifest" of your computer's vitals.

---

### ⚓ Key Features

* **Real-Time Telemetry:** Instant tracking of **CPU** load across all cores and **RAM** consumption using `psutil`.
* **Hacker-Chic Aesthetic:** A beautiful, terminal-native interface with ASCII borders, sparklines, and gauges that look great in any terminal emulator.
* **Low Overhead:** Engineered to be a "stowaway"—monitoring your system with a minimal footprint so it doesn't become the very resource hog it’s trying to track.
* **Keyboard-Centric:** No mouse required. Navigate your system stats with the speed and precision of a seasoned captain.

---

### 🧱 The Tech Stack

* **The Brain:** `Python 3.x` — For rapid development and easy scripting.
* **The Muscle:** `Ratatui` (via Python bindings) — For rendering ultra-fast, flicker-free terminal layouts.
* **The Scout:** `psutil` — For deep-diving into system-level process and hardware information.

---

> "In a world of bloated, web-based monitoring tools, **PyRat** returns to the source. It’s a tool for the purists—those who believe that system monitoring should be fast, functional, and look damn good in a green-on-black terminal."
